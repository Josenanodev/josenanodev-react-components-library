# Josenanodev React Components Library

Reusable React components and hooks for booking flows, property-management tools, forms, modal interactions, galleries, and compact product UI.

## Install

```bash
npm install josenanodev-react-components-library
```

Peer dependencies:

```bash
npm install react react-dom react-icons
```

## Basic Usage

```tsx
import {
  CalendarDatePicker,
  IntegerControl,
  LabeledInput,
} from "josenanodev-react-components-library";

export function BookingControls() {
  return (
    <>
      <LabeledInput label="Guest name" onChange={console.log} />
      <IntegerControl defaultValue={2} minimumValue={1} onChange={console.log} />
      <CalendarDatePicker mode="range" onSelectedDatesChange={console.log} />
    </>
  );
}
```

## Component Groups

### Booking And Availability

- `CalendarDatePicker`: single, multiple, range, and booking date selection.
- `Multicalendar`: virtualized resource/date availability grid.

### Forms And Inputs

- `LabeledInput`: floating-label input with optional formatting and validation state.
- `InputBoxWithConfirmation`: edit-and-confirm text or number input.
- `IntegerControl`: compact numeric stepper.

### Overlays And Navigation

- `Modal`: controlled portal overlay.
- `AlertModal`: status and confirmation dialog.
- `BubbleMenu`: floating action menu.
- `ScreenSteps`: animated multi-step flow.

### Media And Layout

- `ScrollSnapGallery`: native scroll-snap image gallery.
- `StackedCards`: interactive stacked card selector.

## Theme Tokens

Components share a basic visual system through `--trc-*` CSS custom properties. Override them on `:root` for the whole app, or on a wrapper with `data-trc-theme` for a scoped theme.

```css
[data-trc-theme="brand"] {
  --trc-color-primary: #ec6321;
  --trc-color-secondary: #46ba0d;
  --trc-color-text: #333333;
  --trc-color-surface: #ffffff;
  --trc-color-border: #d8d8d8;
  --trc-radius-md: 8px;
}
```

## Documentation Standards

Each component page includes:

- A short description of the intended use case.
- A live example.
- An autodocs arg table with prop descriptions.
- Controls where the prop can be safely edited in Storybook.

For advanced components like `Multicalendar`, prefer reading the prop table before changing examples. Several props affect virtualization, scroll persistence, and callback timing.
